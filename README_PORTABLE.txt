MoneyPrinterTurbo - Rifqi Edition Portable

1. Extract this archive to a normal folder, for example D:\MoneyPrinterTurbo-Rifqi
2. Double-click START_RIFQI.bat
3. The browser opens the Rifqi Edition WebUI
4. For API keys / advanced provider settings, double-click SETTINGS.bat

No separate Python, uv, pip, or dependency installation is required.

Keep config.toml private because it can contain API keys.
